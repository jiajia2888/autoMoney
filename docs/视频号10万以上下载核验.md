# 视频号大拇指10万以上下载核验

日期：2026-11-10，Asia/Shanghai。

用户要求按易起量接口将视频号「徐晶说」大拇指10万+作品全部下载，并在电脑播放。

## 实测结果

- 本地账号2共216条作品，原始likes >= 100000为35条，均为100002（页面保守显示10万+）。本次按大拇指筛选，不把爱心混入门槛。
- 35条逐条调用本机分享API，均取得微信官方shortUrl；分享链接被缓存到对应视频，不改登录态、监控规则或计数。
- 使用项目现有专用DNS客户端，先GET对应官方预览页，再按微信公开merlin.9a5109e8.js契约POST /finder-preview/api/feed/get_feed_info，请求baseReq.generalToken及shortUri。公开预览页没有设置token Cookie，generalToken为空；未借用或猜测其他凭据。
- 每条间隔1秒，单请求6秒，整个批次65.37秒；35条全部HTTP201、errCode=0，但data只有errMsg={type:2,title:"此内容暂时无法播放"}，均无feedInfo或媒体地址。
- 成功保存视频文件0条，电脑播放未接通。不能把Go探测测试退出成功、HTTP201、errCode=0或分享链接当作下载成功。该结果只说明此公开分享接口在本次请求条件下未提供媒体，不等于证明微信全部渠道都不能播放。

## 两个独立阻碍

前次Chrome访问短链接与channels官方展开页均ERR_TUNNEL_CONNECTION_FAILED，这是浏览器代理连接问题。本次独立客户端已能HTTP200取得预览页，仍收到业务不可播放提示，因此解决浏览器代理并不能保证获得可下载媒体。二维码只编码同一个官方分享链接，不保证手机播放。
