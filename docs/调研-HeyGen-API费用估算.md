# HeyGen API 费用核查与批量成本估算

核查日期：2026-11-09。用户场景：合作 IP 的真实视频切片中取人物参考，每种视频准备换装图片，再生成数字人口播，批量字幕后期。

## 当前可核实事实

- 官方开发者索引 https://docs.heygen.com/llms.txt 指明：生产批量应使用 API key，按 API billing；OAuth/部分 MCP 使用网页订阅 credits，不能把两者套餐价格混用。
- 同一索引将 Self-Serve Pricing 指向 https://platform.heygen.com/pricing ，明确说明登录 API dashboard 查看 per-operation prices 和 credit packs。
- 本轮直接请求该价格页只有前端壳；浏览器加载后的真实页面是“Sign in to HeyGen Platform”，没有展示单价。因此没有取得可确认的当前 Avatar IV/V 图片口播 API 美元/分钟价格，也没有读取用户账户、登录或创建 key。
- https://www.heygen.com/pricing 公开显示的是网页产品套餐（如 Creator $29/月、Pro $49/月）；该页本身另有 Explore API pricing，不能拿这些网页价作为批量 API 报价。
- 引擎、操作、分辨率、生成时长、账号合同、用量档及最小计费/舍入规则需以当期账户/API报价核算。未验证的旧价或搜索摘要不能冒充2026-11-09现价。

## 算账方法

先计算实际提交生成的总分钟数，再套用选定引擎与操作的真实单价，另加图片生成、配音、字幕后期及计费规则引起的费用。

假设每天100条、每条30秒、每月30天，则一次成功生成需要1500分钟/月；每条平均生成两次，提交总量是3000分钟/月。若实价为p美元/分钟，对应数字人口播变量成本为1500p或3000p美元，尚未包含其他费用。p是待取得的报价，并非本轮核实的价格。

仅为演示预算敏感性：假如p=1美元/分钟（不是HeyGen现价），则上述分别为1500或3000美元/月。30秒固定费用/最小计费会使线性估算偏低，因此正式预算还要查舍入规则。

## 对用户工作流的影响

每换一套衣服/背景不必为所有脚本重新抽卡：先验收并缓存某个IP的外观模板，再用多条音频复用。换装外观确认后再渲染视频，可降低无效生成和返工。

如果保留原视频原口播音频，TTS/声音克隆并非必需；只有改写台词或需要新旁白时再引入配音模块。字幕按最终保留/生成的音轨对齐。

建议先比较同一组图片、底片与音频在不同引擎中的可用成片率和人工返工时间，获取真实单价后再作云端vs自建盈亏测算。本轮未采购、未上传素材、未调用收费任务、未部署模型。
