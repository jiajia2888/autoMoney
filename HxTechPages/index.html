在项目专用 Chrome 窗口登录抖音，程序会保存这个窗口的登录态。

切换扫码方式会清除已保存的手动 Cookie。普通 Chrome 的登录与此窗口独立。

从已登录的抖音浏览器取得凭据
  1. 打开抖音网页版并登录，按 ⌥⌘I（Windows：F12）打开开发者工具。
  2. 进入 Network / 网络，在筛选框输入 aweme/post，再刷新对标账号主页，选择 www.douyin.com 的作品请求。不要选择 mcs.zijieapi.com 统计请求。
  3. 在 Headers / 标头面板向下滚动，展开 Request Headers / 请求标头（不是 Response headers），复制 Cookie 和 User-Agent 的完整值，分别粘贴到下方。
这里填写完整 Cookie，单个 msToken 或第三方 API Token 不适用。

只保存在本机，保存后不回显。保存仅校验格式；请点击账号的“立即检查”确认凭据有效。此方式不会打开采集浏览器。
