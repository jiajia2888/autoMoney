# autoMoney · 对标账号监控

本地多平台内容工作台，默认进入视频号，可用左侧 TAB 切换抖音。视频号支持扫码登录、作者搜索选择、大拇指过万筛选和双平台定时监控。抖音现有监控继续运行：管理账号、按频率检查、筛选视频点赞、查看上新与首次达标提醒，点击跳转原视频。

## 本机打开

http://127.0.0.1:9010

当前已导入徐晶说此前核对的 20 条历史页面样本，均标记“历史样本”，不是实时采集结果。样本账号自动监控默认暂停。

## 安装与启动

要求 Go 1.25.5、Node.js、uv、官方 Google Chrome。SQLite Go 驱动需要 CGO / C 编译器（macOS Command Line Tools）。

在仓库根运行：

```sh
make collector-setup
make collector-doctor
make migrate
make seed       # 可选，导入已核对样本；重复执行不会覆盖实时视频
make run
```

macOS 可运行 `make service-install` 一次安装本机后台服务，登录系统后自动启动、进程退出自动重启。与 `make run` 二选一，避免重复监听 9010。`make service-status` 查看状态，`make service-stop` 停到下次系统登录（重新启用运行 `make service-install`），`make service-uninstall` 移除自动启动。更新后端时先停止服务再安装新构建。日志位于 `.local/logs`；电脑睡眠或关机期间不检查。

## 视频号对标账号与登录

默认“视频号”TAB → 点击“微信扫码登录” → 用微信扫描网页二维码 → 手机上确认投手账号登录。程序取得 promotewebsessionid 后调用微信身份接口核验，只有通过才显示连接成功，登录弹窗自动关闭并刷新页面状态；早于本次核验的旧登录错误不覆盖新状态。二维码 2 秒轮询、最长 5 分钟，关闭弹窗取消本次任务；过期可刷新。身份与最后核验时间显示在视频号页；“核验会话”可确认当前有效性，“断开连接”删除本机会话。

连接后点击“添加对标账号” → 输入一个或多个昵称（每行一个或逗号分隔，每批最多20个） → 点击右下角“搜索作者” → 核对头像、简介与身份后勾选 → 一次添加选中作者。已有账号标为已添加；每组可查看更多或单独重试。统一检查间隔默认60分钟，可调整，添加后开启自动监控；规则可在账号页修改。视频号门槛固定为**大拇指严格大于 10,000**（10000 不入选，10001 入选），爱心数单独显示，不当收藏或相加。首次扫描建立历史基线并筛出已有过万作品，不把历史作品推送成新视频。

每批最多 500 条、100 页，每页 5 条；达到数量/页数上限会保存不透明游标和固定历史时间范围，自动监控开启时 30 秒后续扫更早作品，直到接口明确返回结尾。暂停后不会自动续扫；“立即检查”可继续当前历史进度。空结果、重复游标、未知计数、作者不符等明确报错，不写入不完整失败响应。

视频号列表默认只显示当前大拇指 >10000 的作品；可选“首次建档前的历史作品”或“建档后发布的新视频”，并按发布日期和首次发现过万日期筛选。首次观察时已过万会注明实际达标时间未知；已有低位观察后首次过万保留首次日期，重复检查不重复提醒。历史扫描到结尾后按规则检查近期作品；单轮扫描范围外的旧作品不会持续更新。统计中的已收录视频也包括未过万作品，用于判断后续达标，列表默认隐藏这些作品。

作品卡片“打开原视频 / 微信扫码”按需取得官方分享链接，弹窗提供本地生成二维码、复制和电脑打开。电脑打开优先使用官方短链接展开地址；Chrome 若报 ERR_TUNNEL_CONNECTION_FAILED，表示浏览器代理连接失败，可换网络或用手机微信扫码。二维码展示不代表手机已验证播放；这不是 MP4 下载，元宝视频下载有独立入口，双平台口播转写可自动下载或复用本机视频。

当前接口部分大拇指/爱心原始值为 100002，前端保守显示“10万+”并注明非精确数量；尚未找到微信对此特殊值的正式定义。数据库保留原值，过万筛选口径不变。抖音与视频号的数据、筛选和登录态独立，后台共用串行队列。

本项目独立向微信官网请求，不依赖易起量部署，不读取其他项目 Cookie。会话用 AES-GCM 加密保存在 .local/wechat-session.enc，密钥 .local/wechat-session.enc.key，两者均为 0600 且不提交；加密保护不替代本机账户权限。微信当前返回超大的 Cookie Max-Age，客户端在进入 Go CookieJar 前将正有效期限制为最多 400 天，防止整数溢出；删除、路径、域名和 Secure 规则保留，这不代表微信保证 400 天有效。API 不回显 Cookie。服务重启后可读取已保存会话，但不保证永不过期。2026-11-09 已真实扫码、核验微信投手身份并保存会话；取得二维码本身不等于登录成功。

本机微信域名经代理 DNS 返回虚拟地址，导致 TLS 失败；已在忽略的后端 config.json 设置 wechat_dns_server=223.5.5.5:53，仅微信客户端使用该 DNS 并直连，保留官方域名 TLS 证书验证，不改系统 DNS。其他机器默认使用系统网络；遇到同类问题可配置该项或 AUTOMONEY_WECHAT_DNS_SERVER（IP:53）。不应硬编码微信服务器 IP。

## 视频号视频下载（元宝）

视频号列表每行点击“下载视频” → “获取元宝登录二维码”，在当前弹窗扫描元宝官方二维码并在手机确认。后台使用项目独立Playwright Chromium会话，二维码真正就绪后才提示扫码。首次运行先执行 `make yuanbao-browser-setup` 安装配套官方浏览器。程序只保存本项目元宝会话，检测到登录后自动尝试当前视频；下载及完整解码校验通过后才显示“保存MP4”。没有手动复制Cookie步骤。元宝登录与原视频号投手登录分别保存，监控继续使用投手会话。

媒体链路按GitHub ltaoo项目的元宝协议独立实现：官方分享URL → 元宝get_parse_result → 新token/eid → 微信预览 → 腾讯媒体；没有运行整套抓包工具或安装代理证书。仅接受已收录作品；单条150MB、30分钟以内，任务4分钟超时，HTTP/业务/文件失败均明确显示。元宝凭据位于`.local/yuanbao-credentials.json`（0600，不提交、不回显）；微信分享请求仍使用原加密投手会话，元宝Cookie不发送给微信预览或CDN。可取消正在等待的登录；关闭下载弹窗不停止后台登录/下载，登录最长6分钟。

已真实验收元宝登录及一条视频号下载：本地视频335，14,993,930字节、241.58秒、H264 720×1280+AAC；完整解码通过，“保存MP4”浏览器下载副本与原文件SHA256一致。详细结果见docs/handoff.md。页面内播放器已接通，批量下载仍未接通，不把会话保存当作视频下载成功。

## 抖音登录

切换“抖音”TAB 后点击右上角“连接抖音 / Cookie”，可选择两种方式：

- 扫码登录：在项目专用 Chrome 窗口扫码，登录态与普通 Chrome 独立，保存在 .local/douyin-profile。
- 手动填写 Cookie：从已登录抖音的浏览器 Network 请求头复制完整 Cookie 和同一浏览器的 User-Agent。入口内有步骤。保存一次后自动复用，登录失效再更新；这不是单个 msToken 或第三方 API Token。

手动 Cookie 校验兼容 Chromium 原始请求中的无名 Cookie（无等号的 token 片段）：保留原始 HTTP 头，只从有名称的字段提取登录与签名参数；无名片段不能代替 sessionid。重复命名字段、非法名称及换行仍拒绝。

手动配置保存在 .local/douyin-credentials.json，文件权限 0600，不提交到 Git；接口不回显凭据，页面关闭时清空输入框，不使用浏览器 localStorage 保存。保存仅验证格式，需点击账号的“立即检查”确认凭据有效。手动模式复用原专家客户端与 Node 签名，不启动采集浏览器。切回扫码会清除手动配置。

进入“对标账号”添加完整主页链接、账号显示名、检查间隔和门槛，或调整已导入的徐晶说。普通抖音号目前只内置已核验的 80185543890；其他账号请用完整主页链接。名称为你填写的显示名，不承诺自动解析。

点击“立即检查”建立本次范围的历史基线，然后启用自动监控。后台在 Go 服务运行期间按规则检查，网页无需一直打开；电脑/服务关闭则暂停。平台内显示提醒，首版没有外部消息推送。

每次默认最多扫描 100 条，可设到 500；要覆盖徐晶说当前 349 个作品，可将上限调为 500。置顶、图文过滤等会影响扫描条数；范围外老视频不会更新点赞，检查记录显示是否完整。

## 可用功能

- 多账号添加、修改规则、暂停/启用、删除及本地持久化。
- 自定义检查间隔（5 分钟至 7 天）、扫描上限及点赞门槛。
- 手动检查、串行定时任务、重启中断记录、停止当前任务。
- 视频按账号、关键词、严格大于点赞数筛选，按点赞/发布时间/收录时间排序、分页；“精确数据”排除历史约数样本。
- “过万记录”按北京时间的首次发现日期分组、筛选；首次收录已过万会标注实际过万时间未知，历史样本不补造日期。
- 每条视频可点击“提取文案”，区分发布描述和视频口播；本机转写结果可复制、下载 TXT / SRT，支持重试和停止。
- 新发布提醒、首次过门槛提醒，重复任务不重复发送；平台内已读标记。
- 专家抖音分页客户端适配；原始点赞数缺失、登录失效、接口失败等明确报错，不返回假成功。

视频发现采用紧凑行列表，保留小缩略图、完整标题提示、账号、点赞/大拇指、发布和发现日期；操作集中在每行右侧。双平台每行均有“提取文案”，未下载时先自动保存视频，再用本机 Whisper 转写；已有文件直接复用。已下载行显示绿色标记、首帧封面和播放按钮，点击封面直接本地播放；“已下载”页签按当前筛选查看本机文件。文案弹窗仅展示视频口播正文及复制、TXT/SRT下载；发布描述不再占用页面。

视频列表底部分页旁可切换“显示全部 / 分页显示”，只显示当前平台和当前筛选命中的全部本地记录，不触发额外平台采集。

双平台视频下载状态见 [下载方案](docs/双平台视频下载方案.md)。抖音已按专家直链方式真实下载并校验一条1080×1920 MP4；视频号元宝单条下载及浏览器保存已真实验收一条720×1280 MP4。GitHub调研及接入边界详见[视频号下载接入评估](docs/视频号下载接入评估.md)。

## 本机提取视频文案

抖音复用专家 DouYinClient 详情与媒体地址提取，视频号复用元宝下载；双平台共用本机 FFmpeg（含 ffprobe）、whisper-cli 和模型 ~/.cache/whisper/ggml-large-v3-turbo-q5_0.bin。可用 .venv/bin/python scripts/extract_copy.py --doctor 检查；模型与脚本可在后端配置 whisper_model / transcript_script 中调整。音频不上传到云端，提取结果保存在本地数据库。

支持单条视频 150MB、30 分钟以内的口播转写。点击视频的“提取文案”会启动本机任务，关闭弹窗后仍继续；成功后可复制、下载，重复打开复用结果。发布文案与口播分别展示，历史样本标题不当成完整发布文案。下载通过专家已签名详情接口取得目标作品的媒体候选，流式保存并验证视频；不再依赖 yt-dlp 详情接口。下载优先复用手动保存的 Cookie；没有手动配置时，后台读取本项目专用 Chrome profile 的登录态，不打开可见认证窗口，也不读取普通 Chrome profile。专用窗口或采集正在使用 profile 时会提示稍后重试。失败时点击弹窗中的“配置 Cookie”，保存后回到原视频点击“重新提取口播”。

2026-11-10 已使用本项目Cookie，通过专家详情与媒体链路下载作品7639685139231984939：30,366,613字节、288.33秒、H264 1080×1920+AAC，完整解码通过。同一作品完整下载到本机Whisper转写通过，生成1142字口播和SRT。此前yt-dlp失败不能代表专家链路不可下载。无需反复保存相同配置；平台要求时需由用户主动完成认证，不能承诺一次认证永远有效。后台检查静默运行，只有主动点击登录才打开可见窗口。页面服务断连会单独提示，不当作 Cookie 失效。

抖音网页下载：切到“抖音” → 视频列表每行右侧“下载视频” → 完成后点“保存MP4”。关闭弹窗仍继续下载；已校验的本机文件直接复用，保存到浏览器下载目录。当前串行下载单条视频，不含批量下载。

抖音单条下载命令（仅下载，不运行转写）：

```sh
.venv/bin/python scripts/download_douyin.py --url https://www.douyin.com/video/7639685139231984939
```

默认输出到 `.local/downloads/douyin/<作品ID>.mp4`，已存在文件不覆盖。仅项目登录态，最多3个媒体候选、150MB、30分钟、总计180秒；下载临时文件校验成功后才发布，页面/空文件不算成功。当前页面没有独立批量视频下载按钮。

## 认证异常与本地媒体

监控检查发现失败时，当前平台顶部持续显示失败原因并提供检查记录和连接入口；识别到登录/会话失效时将连接按钮标为“登录需检查”。下载和转写失败同时显示具体原因。认证失效是在下一次实际检查、核验或下载请求时发现，不承诺即时离线感知；网络超时不会直接判为 Cookie 失效。视频号投手和元宝需要分别登录。

2026-11-10 已真实验证视频号335本地播放（241.58秒，播放时间推进）及复用MP4转写935字；第二条334未下载视频经一次网络失败重试后完成自动下载和转写，支持TXT/SRT。当前本地服务已恢复运行；本轮LaunchAgent启动遇到工作目录“Operation not permitted”，暂由直接启动的进程提供服务，后台自启恢复尚待处理。

## 视频切片

双平台视频行点击“切片”，默认按源帧序列均匀提取30张，数量可设1–300；也可选“按时间间隔提取”，设置每0.1–3600秒一张（首帧起算，取到达间隔的下一实际帧）。短视频不足指定帧数时按实际数量提取，不重复补图。未下载时先沿用原下载流程，已下载直接复用，保留原分辨率JPG，支持预览和ZIP下载。关闭弹窗继续，可停止；相同设置复用结果，不同设置独立缓存。单次最多1000张/1GiB图片/20分钟，超限明确报错。此前逐帧产物仍保留在.local/frames旧目录，不混入新的30张结果；目前没有页面清理入口。
